# Web-Scrapping
This web scraping project involved extracting data about colleges from a website and developing a college recommendation system based on ranking, affordability, and location.
This project is ongoing.

## Description 
In this project, data was scraped from a website using BeautifulSoup and Requests. The raw data was then cleaned and modeled using Pandas and NumPy. The cleaned data was saved as a CSV file for further processing.
